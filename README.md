## 🧩 Practical Projects & Current Focus

I focus on building practical features that connect mobile interfaces, API communication, and reliable data handling—not just listing technologies.

### 📱 Mobile App Development

- **E-Commerce workflows:** API-driven product catalog, categories, search, product details, authentication flows, and a cart persisted locally between app sessions.
- **Business management with Masiter:** product and inventory tracking, customer records, sales invoices, outstanding balances, cloud data, and product-image storage.
- **API-driven News App:** headline and category browsing with English and Arabic search results.
- **Local-first Meals App:** onboarding, validated meal forms, meal details, and SQLite storage for saved meals.

### 🖥️ Backend Development — Current Learning Focus

**Inventory & Orders REST API · Node.js + Express.js + MySQL**

A practical backend direction for a small-store system:

- Registration, login, and protected API routes.
- Product and category endpoints, inventory quantity, and stock validation.
- Relational MySQL tables for users, products, orders, and order items.
- Request validation, centralized error handling, filtering, search, and pagination.
- Transactions for multi-step order creation and inventory updates.
- Endpoint testing and API documentation with Postman.

> **Current focus:** building backend skills and connecting a Flutter client to a well-structured REST API. The backend list above describes a learning/building scope, not a claim that every feature is already shipped.
